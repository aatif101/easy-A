# USF Bull asset

`usf-bull.svg` is the official standalone Bull-U symbol, downloaded unchanged on
2026-10-07 from the [USF Athletics website](https://gousfbulls.com/).
That site uses this exact SVG as its mobile logo and in event listings.

- [Original asset](https://dxbhsrqyrr690.cloudfront.net/sidearm.nextgen.sites/usf.sidearmsports.com/images/nextgen_2026/logo_mobile1.svg)
- Original dimensions / viewBox: 56 × 56 / `0 0 56 56`.
- Original fills: USF green `#006747`, gold `#CFC493`, and white.
- SHA256: `93996518EB584D50ECB5703E7130A1C61037E54384D8868074B9631C4F7D2F58`.

The file contains only the Bull-U symbol and its registration mark, with no university
wordmark. No paths, colors, proportions or content have been modified. The header
scales it uniformly to 28 px on mobile and 32 px at the `sm` breakpoint and above.
The mark remains USF's property; this source record does not assert permission or
affiliation. Easy-A's existing independent-project footer remains in place.
