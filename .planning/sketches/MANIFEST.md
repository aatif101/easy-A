# Sketch Manifest

## Design direction

A calm, contemporary student guide for USF Tampa course selection. Give known-course lookup
and discovery equal prominence. Lead with observed outcomes and visible denominators; place
the frozen calculated score in expanded evidence. One result per course, then complete section
choices. White and light neutral surfaces, readable sans-serif type, restrained green.

## Reference points

User-supplied student-experience plan, 2026-09-25. Existing Easy-A green identity retained.
GSD sketch workflow used in quick mode: the supplied plan already establishes the design
direction, alternatives, and scope. Frontend-design informs visual choices; UI UX Pro Max
supplies targeted focus, labeling, and responsive checks. The user selected A on 2026-09-25;
production implementation and student validation have not started.
