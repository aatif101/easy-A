## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator XLSX -> parser/grade ingest | Workbook identifiers and counts are untrusted local file input before validation and canonical lookup. |
| Grade ingest -> canonical database | Parsed subject+number becomes a Course foreign key while term/CRN/source identity and provenance must remain intact. |
| Canonical history -> analytics/cache/search | Evidence must reach current-term consumers without turning a global prior into claimed course history. |
| Workspace -> Git | Grade exports may contain source-controlled or sensitive institutional data and must remain outside version control. |
