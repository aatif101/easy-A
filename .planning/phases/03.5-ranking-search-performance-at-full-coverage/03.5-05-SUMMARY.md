# Phase 03.5 Plan 05: Performance Benchmark & Postgres Verification Summary

Built a repeatable rankings-search benchmark harness and a live-seat Postgres integration test, then
measured the rewritten SQL search at full projected scale against real infrastructure. Quality gate
and the Postgres-path suite pass; the full-scale p95 target is missed and deferred as an accepted
deviation.

## Task outcomes

**Task 1 — benchmark harness + Postgres test (commit `17c271b`): COMPLETE.**
`scripts/benchmark_rankings_search.py` seeds a parameterized synthetic dataset (default 3,782
sections), populates `section_rankings`, and times representative `search_rankings` calls, reporting
p50/p95/max with dataset size + environment. Outside `--smoke` it works inside a throwaway schema
that is always rolled back (never writes the real coverage DB — D-04). Self-verified in `--smoke`.
`tests/refresh/test_postgres_coverage.py` gained a live-seat-freshness test (seats update while
cached analytics stay byte-identical). `ruff` + `mypy --strict` clean.

**Task 2 — measurement: PARTIAL (2 of 3 criteria met, 1 deferred).**
- ✅ **Quality gate:** `check_data_quality.py --term 202701` → **0 errors** (132 sections, 2026-09-20).
- ✅ **Postgres-path suite:** **256 passed, 0 failed** with `EASY_A_TEST_POSTGRES_URL` exported.
  (The 6 failures seen earlier were a stray uncommitted `config/course_targets.toml` edit — 5
  out-of-scope courses bumping the pilot 5→10 — since reverted; they were never a Postgres problem.)
- ❌ **AFTER p95 < ~1.5s:** **NOT met — ~2.40s at 3,782-section scale.** See `03.5-PERF-REPORT.md`.
  Environment-label caveat: the run used `DATABASE_URL` (no `--url`), so the harness mislabeled the
  target "local Postgres"; the ~15-minute remote seed indicates Supabase but it is not certified.

**Task 3 — human sign-off: RESOLVED WITH DEFERRAL (2026-09-20).**
User accepted shipping the pilot with the full-scale p95 gap deferred to a post-pilot tuning pass,
recorded as an accepted deviation in `.planning/WINDOWS.md`. The gap is at a synthetic projected
scale, not the current ~132-section Tampa pilot; the residual work is additive index/query tuning,
not a rewrite, so it does not block downstream development.
