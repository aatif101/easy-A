- Added course-scoped `refresh_section_rankings()` calls to `refresh_targets()` inside the existing caller-owned transaction, so ingest and cache writes succeed or roll back together.

## Decisions Made

- Kept course cache refresh inside `refresh_targets()` rather than adding a second transaction; the caller remains responsible for commit or rollback.
- Kept `refresh_data()` cache population as an independent stage because its other ingest stages commit independently.
- Filtered the HTML handed to `ingest_schedule_html()` as well as the parsed guard rows; otherwise that function would reparse the original response and ingest the excluded suffix rows.
- Kept REQ-PERF-01 open because hosted full-coverage p95 measurement and the PostgreSQL-path gate belong to Plan 03.5-05.
