<objective>
Answer OQ-03 with evidence: how available are current-term syllabi across the declared launch
scope, and does that make the historical-source path primary rather than a fallback for Phase 3.

syllabus client fetches exactly one already-known document; nothing in the repository can search or
enumerate. A two-course sample found no current-term syllabus, which is a risk signal, not a
campus-wide fact.

sampled pass with per-observation states and timestamps, and the Phase 3 ordering recommendation.

choice is a human decision because it commits the project to a new external surface or declines to.
</objective>
