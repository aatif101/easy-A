## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner -> third-party actions | Action code runs with the workflow token |
| Pull request -> CI | Untrusted PR code executes in CI |

| T-09-02 | Elevation of Privilege | workflow GITHUB_TOKEN | medium | mitigate | Top-level `permissions: contents: read`; no secrets context referenced (asserted by tests/test_ci_workflow.py); CI never receives DATABASE_URL, so PR code cannot reach hosted Supabase |
