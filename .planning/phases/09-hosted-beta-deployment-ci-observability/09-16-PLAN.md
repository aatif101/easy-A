## Design (the semantics every task implements)

A single operator fraction X (`--max-missing-fraction X`, only with `--once` or `--dry-run`) is the largest share of the term the operator accepts losing. `gate_thresholds(override)` in `src/easy_a/sync/gate.py` maps it onto evaluate_gate's four keyword thresholds:

| Rule (reason prefix) | No flag (`override is None`) | X at or below 0.10 | X above 0.10 |
|---|---|---|---|
| `zero_rows` | refuse an empty scoped response | unchanged | unchanged, never overridable |
| `missing_fraction` | `max_missing_fraction` 0.10 | X | X |
| `row_floor` | `min_row_ratio` 0.90 of the last succeeded `records_seen` | 0.90 | 1 - X, exact decimal |
| `subjects_absent` | `max_absent_subject_fraction` 0.02, `min_absent_subjects` 2 | 0.02, 2 | X, 2 |

Why this shape. It is route (a) from the verification report. The defaults are the literal constants, so the no-flag gate is unchanged. `gate_thresholds(0.10)` equals the defaults, so the help text's "default 0.1" is true. Today's override semantics for `missing_fraction` are kept, including tightening. Only an explicit X above the default relaxes `row_floor` and `subjects_absent`, and each relaxes to the same loss X. An empty response is never a legitimate removal. A truncated response is caught when `subjects_absent` names subjects USF still lists; the runbook covers that check by hand before any override. Removals are reversible `removed_at` marks (CONTEXT D-06 carried design), and `--restore-crn` exists.
