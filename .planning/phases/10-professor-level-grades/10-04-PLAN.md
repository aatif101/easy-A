<objective>
Render the per-instructor breakdown inside RankingDetails exactly as the approved UI-SPEC specifies, against the API contract below, with tests for every state.

Purpose: REQ-PROF-01 requires a named instructor's grade history shown next to the course-wide history, with denominator, term count and source on every figure (D-06, D-07). CONTEXT D-09..D-15 lock placement, list rules, row format, lab handling and the co-teaching caveat.
Output: types, utilities, the InstructorBreakdown component, its integration in RankingDetails, tests, and synthetic mock-mode fixtures.

API contract (implemented by plan 10-05; field names chosen under CONTEXT "Claude's Discretion"). `ranking.historical_analytics.instructor_breakdown` is either null or an object with:
- `status`: "ready" | "lab_section" | "no_instructor_history"
- `instructors`: array, server-sorted (current first, then effective_n desc, then name asc). Each row has `name` (string), `a_share` (0-1 raw share of A among A-F), `effective_n` (the denominator, shown as "{n} grades"), `term_count`, `first_term` and `last_term` (Banner codes such as "202501"), `easiness_score` (number, or null when not scored), `scored` (boolean) and `is_current` (boolean).
- `current_instructor`: the section's named instructor, or null for Staff, blank or ambiguous.
- `current_instructor_has_history`: boolean.
- `other_instructor_count`: number of instructors under the collapse cutoff, excluding the current one.
- `scoring_min_effective_n`: the {N} in "Under {N} grades".
- `collapse_min_effective_n`: the {C} in the Others line.
- `provenance`: RankingProvenance.

UI-SPEC to contract mapping: grade_count is effective_n; shrunk_score is easiness_score; scoring_min_grades is scoring_min_effective_n; others.instructor_count is other_instructor_count; current_instructor.row is the row with is_current, absent when current_instructor_has_history is false. The breakdown is embedded in the ranking item, so the UI-SPEC loading and error states are not built (UI-SPEC: "if embedded, they do not render").
</objective>
