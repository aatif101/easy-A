<objective>
Turn the backfill CLI into the D-04 rollout instrument: a dry run that shows the exact before/after ranking diff and join re-measure without committing anything, an apply that goes live atomically under the sweep lock, and cheap undo paths.

Purpose: the hosted worker rebuilds the cache with whatever code is deployed after every changed sweep. If the historical rows were committed without a reviewed diff, the next sweep would publish unreviewed scores. Computing the what-if inside a rolled-back transaction gives the D-04 review on real data before any commit. Rebuilding inside the apply transaction makes go-live a single atomic step.
Output: extended backfill CLI, tests, and an operator runbook.

Reversibility: the data write is rated costly. It is undone by `--rollback --yes`, and the scoring change by reverting constants and running `--rebuild-only`. Neither is a one-way door, so no reversibility checkpoint is inserted here; the D-04 human review gate is plan 10-07's checkpoint.
</objective>
