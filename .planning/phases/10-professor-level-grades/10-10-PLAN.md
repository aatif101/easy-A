<objective>
Close 10-VERIFICATION.md gap 2 (review finding P10-WR-01): the instructor panel must never state that instructor-level history is absent when history is recorded.

Today `web/src/components/InstructorBreakdown.tsx` line 135 sets `isEmpty = !named && breakdown.instructors.length === 0`, ignoring `other_instructor_count`. The backend (`src/easy_a/analytics/queries.py` lines 124-173) returns status `ready`, `instructors` empty and `other_instructor_count` N > 0 when every instructor with history is under the 15-grade collapse cutoff and no current instructor is pinned (Staff, blank or ambiguous section). The UI then prints the dashed note saying no instructor-level grade history is recorded directly above "N other instructors with under 15 grades each". That is a false statement on the live site and breaks the core value (PROJECT.md D-06/D-07).

Fix (per the verifier's and reviewer's prescription): gate the empty note on `othersCount === 0` too, and in the collapsed-only state render the normal Staff block (heading "Historically taught by", Source line, Staff explainer) followed by the Others line, with no empty list. No new copy: every string used already exists in the UI-SPEC Copywriting Contract.

**UI-SPEC amendment flag:** the approved 10-UI-SPEC.md row "Empty state body (course has history, zero qualifying instructors and Staff section)" literally mandates the defective rendering, because "qualifying" means at or above the collapse cutoff. This plan amends that row's CONDITION only (Task 2), dated, citing P10-WR-01. No locked copy string is added, removed or reworded.

Purpose: remove a false statement from the student-facing panel and pin the state with a regression test.
Output: a red-then-green vitest regression test, the one-condition fix, the dated UI-SPEC amendment, and the P10-WR-01 disposition update.

Tracer-first: Task 1 is the tracer. Its slice runs the real API payload shape for this state through RankingTable, RankingDetails and InstructorBreakdown in both the desktop and mobile layouts: a failing test first, then the fix, then green.
