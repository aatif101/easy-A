<objective>
Move seat freshness from "latest snapshot time" to "last verified time". A change-only sync only writes a snapshot when seats change, so without this an unchanged section would look stale. The thresholds become cadence-aware per D-10.

Purpose: REQ-SYNC-01 says the UI shows when data was last verified. RESEARCH Pitfall 5 found the fixed 600/1800 s thresholds would mark every section stale most of the day at the hourly cadence.
Output: freshness module change, optional override settings, two call sites in the rankings path, tests.
</objective>
