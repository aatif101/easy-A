<objective>
Turn a scoped whole-term fetch into a change-only, single-transaction update of Spring 2027 sections: instructor and seat rows only on change, `removed_at` for vanished CRNs, restore on reappearance, bulk `last_seen_at`, cache upkeep only on structural change, one IngestRun per sweep, failure evidence that survives rollback, and a read-only dry run.

Purpose: This is the core of REQ-SYNC-01 and ROADMAP Phase 9 success criterion 4. The legacy ingest appends an instructor row and a snapshot for every section on every run, about 1.1M rows a day at 5-minute cadence, so the sync must be change-only by construction.
Output: `easy_a.sync.plan`, `apply`, `sweep` and four test files.

Recorded decision (research Open Question 4): IngestRun has no summary column, so the full change summary goes in the returned SweepOutcome, which the CLI logs as one JSON line (09-11). The records_* columns carry the counts defined in must_haves, and no JSON column is added (migration 0004 stays minimal).
</objective>

## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-22 | Tampering | partial or poisoned sweep | high | mitigate | Gate before any write; one transaction; failure rollback proven per failure kind; removals are reversible marks restored on reappearance |
| T-09-23 | Information Disclosure | IngestRun.error_message | medium | mitigate | Kind prefix + sanitized detail (URL stripped, 500-char cap); /sync-status exposes only the kind (09-06) |
| T-09-24 | Repudiation | unrecorded sweeps | low | mitigate | Every real sweep writes an IngestRun (success in-transaction, failure in a second transaction); busy/dry-run are the only unrecorded paths and make no writes |
| T-09-25 | Denial of Service | DB round trips / cache rebuild | medium | mitigate | Three bulk reads, chunked bulk last_seen_at, rebuild only on structural change |
| T-09-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package added |
</threat_model>
