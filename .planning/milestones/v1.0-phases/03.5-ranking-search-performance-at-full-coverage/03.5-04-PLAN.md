<objective>
Extend the existing campus-cleanup tooling (`clean_other_campus_sections`) so it explicitly deletes
and verifies `section_rankings` rows for any section it removes — matching the audited
explicit-delete + identity-verification pattern it already applies to SeatSnapshot / SectionInstructor
/ Syllabus. This closes the orphaned/stale-cache regression that a future non-Tampa cleanup run
would otherwise reintroduce (RESEARCH Pitfall 2).

Purpose: the FK `ondelete="CASCADE"` (Plan 01) protects referential integrity, but cleanup.py
deliberately does its own explicit, verified deletes for dependent-data safety and audit; the cache
table must join that pattern or a delete either violates the FK or leaves a silent orphan.
Output: the extended cleanup sequence + a cascade/identity test.
</objective>
